# Recording stockroom and delivery observations

## Organisation
Describe the location and condition actually observed. For example, “five boxes outside the designated storage area” is more useful than “the stockroom is bad”. Keep quantities exactly as reported. If the number is unclear, ask rather than guessing. Also record a tidy or correctly labelled area when the visitor mentions it.

## Delivery discrepancies
Useful facts include the delivery reference, delivery date, expected quantity, received quantity and which packaging was damaged. These details may be unknown at the time of the visit. Mark unknown values as unknown; do not calculate a discrepancy from figures that were not supplied.

## Follow-up mentioned by the visitor
If the visitor explicitly says that someone should check the delivery register or reorganise an area, include the request in the report with the stated name and date. Do not promise replacement products, place an order or assign work merely because a discrepancy was observed.

## Existing information
A previous report can help the regional manager ask whether an issue persists. The new report must state only what was observed or explicitly confirmed during the new visit. A correct area today does not silently change the content of an older report.
